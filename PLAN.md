## 2. Copyright and safety rules (these protect the channel)

Rockstar's rules (from its "Policy on posting copyrighted Rockstar Games material"), plus what Take-Two actually took down:

1. **Never re-upload trailers, screenshots or press art from Rockstar.** Take-Two has struck full-trailer re-uploads and reaction videos that play the whole trailer with its audio.
2. **Never post leaked footage or leaked files.** Take-Two strikes these fast, and 3 strikes delete the channel. Rumours are allowed only as **text in our own words**, marked **RUMOUR**, with 2 sources.
3. **No story spoilers:** no ending, no big twists, and no clips that are only a cutscene. Every story-related post gets "SPOILER" on its cover.
4. **No AI fakes made to look like real GTA 6 footage.** One fan account got a cease-and-desist for this.
5. **No "GTA" or "Rockstar" logo in our name or logo.** Meta and YouTube may reject a page that looks official. The name must not pretend to be Rockstar.
6. **Your own gameplay is fine.** Rockstar welcomes gameplay clips and narrated "let's play" videos. **One grey area:** Rockstar's policy says "non-commercial", but in practice thousands of channels earn money from GTA gameplay. Turning on monetization is your choice, and the risk is small but real.
7. Same rules as FMM:
   - Cross-check every fact with a 2nd source.
   - No engagement bait ("tag a friend", "like if…").
   - Covers are never black.
   - Only the cloud posts, never the PC.
   - Never commit tokens. The repo is public.
   - Never paste tokens in chat. **This Claude account is shared with your sister.**

## 7. How it runs by itself, for free

Same proven design as FMM, but a fresh copy:

```
News sources (Rockstar Newswire + IGN/GameSpot/Eurogamer/PC Gamer RSS, YouTube trends)
        │  keep a story only if 2 sources say it
        ▼
Your clips (Google Drive "GTA6 Inbox", owned by the NEW Gmail)
        ▼
GitHub Actions (new PUBLIC repo = free unlimited minutes, runs every 2 h, PC can be off)
   ├─ make card / Reel / cover (Python + ffmpeg, our fonts & colours)
   ├─ write caption (our own words; optional free Google Gemini key for rewording)
   ├─ post to Facebook + Instagram (Meta Graph API, new app, new token)
   ├─ post to YouTube (see note A)
   └─ drop the same video in Drive "Ready for TikTok" → you upload from phone
        ▼
Weekly growth report (Mondays): which formats got views → do more of those
Backup trigger: Google Apps Script on the new Gmail (like FMM's) restarts it if GitHub skips runs
```

Cost: **0 taka.** GitHub (public repo), Google Drive, Apps Script, Meta API, YouTube API and Gemini's free tier are all free.

Separation from FMM:

- New repo (e.g. `gta6-automation`; your same GitHub login is fine).
- New Gmail, new Meta app, new secrets.
- FMM code is **copied as an idea**, never edited.
